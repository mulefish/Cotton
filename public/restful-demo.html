RESTful API Demo

This page demonstrates RESTful API principles using HTTP methods: GET, POST, PUT, DELETE

📋 GET - List All Items

GET /api/items

Retrieve all items from the server.

🔍 GET - Get Single Item

GET /api/items/<id>

Retrieve a specific item by ID.

➕ POST - Create New Item

POST /api/items

Create a new item. The server will assign an ID.

✏️ PUT - Update Existing Item

PUT /api/items/<id>

Update an existing item. All fields are required.

🗑️ DELETE - Delete Item

DELETE /api/items/<id>

Delete an item by ID.
